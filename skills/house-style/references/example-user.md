# Personal style rules (example)

Copy this file to `~/.claude/house-style-user.md` and replace every rule
with your own. The house-style skill folds these into any editor agent it
creates or coaches; agents never read this file at run time, so edits here
reach an agent at its next coaching session.

Keep each rule one line and mechanical enough to check — "prefer plain
language" teaches an agent nothing it can act on.

- Use US spelling and units.
- Replace em dashes with commas.
- Oxford comma, always.
- Numbers under ten are written as words.
- Cake-themed puns are load-bearing; leave them alone.
